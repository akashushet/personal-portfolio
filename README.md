## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or run a lightweight local HTTP server:

```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Open your GitHub account: [https://github.com/akashushet](https://github.com/akashushet)
2. Create a new repository named `portfolio` or `akashushet.github.io`.
3. Push or upload all files from this directory into the repository's `main` branch.
4. Go to **Settings** → **Pages**.
5. Under **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` / `root`
6. Click **Save**. Within 1–2 minutes, your live portfolio will be active at:
   `https://akashushet.github.io/` or `https://akashushet.github.io/portfolio/`
